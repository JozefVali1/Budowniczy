# Budowniczy — Planer budżetu budowy

Aplikacja PWA do planowania budżetu i materiałów budowlanych.

## Instalacja na GitHub Pages (krok po kroku)

### 1. Utwórz konto GitHub
Wejdź na https://github.com i zarejestruj się (bezpłatne).

### 2. Utwórz nowe repozytorium
- Kliknij **+** → **New repository**
- Nazwa: `budowniczy`
- Zaznacz: **Public**
- Kliknij **Create repository**

### 3. Wgraj pliki
- Kliknij **uploading an existing file**
- Przeciągnij WSZYSTKIE pliki z tego folderu:
  - `index.html`
  - `manifest.json`
  - `sw.js`
  - folder `icons/` (z plikami icon-192.png i icon-512.png)
- Kliknij **Commit changes**

### 4. Włącz GitHub Pages
- Wejdź w **Settings** (górne menu repozytorium)
- W lewym menu: **Pages**
- Source: **Deploy from a branch**
- Branch: **main** → folder: **/ (root)**
- Kliknij **Save**

### 5. Poczekaj ~2 minuty
Twoja aplikacja będzie dostępna pod adresem:
`https://TWOJA_NAZWA_UZYTKOWNIKA.github.io/budowniczy`

### 6. Zainstaluj na iPhonie
- Otwórz ten adres w **Safari**
- Naciśnij ikonę **Udostępnij** (kwadrat ze strzałką)
- Wybierz **"Dodaj do ekranu głównego"**
- Naciśnij **Dodaj**

Gotowe! Aplikacja pojawi się na ekranie głównym jak normalna apka.
Działa też **offline** — bez internetu.
